Đọc bình luận live Facebook cá nhân

Cài Social Stream Ninja ↗ trên Chrome, mở video live dưới góc nhìn người xem và bật thu thập bình luận. Trong SSN bật “Enable remote API control of extension” và “Send chat messages to API server”, rồi dán Session ID ở đây. Giữ tab Facebook mở khi live.

Chưa lưu Session ID.

Phát Facebook cá nhân

Mở Facebook Live Producer ↗, chọn trang cá nhân và Phần mềm phát trực tiếp. Sao chép URL máy chủ và khóa luồng vào hai ô dưới đây.

Khóa chỉ lưu trong .env trên máy Vast, không hiển thị lại trên web.
Lưu cấu hình, khởi động luồng, rồi mới gửi tín hiệu Facebook.

Sau khi Facebook nhận tín hiệu, kiểm tra hình/tiếng trong Live Producer và bấm Phát trực tiếp tại đó. Nút Khởi động luồng chưa gửi tín hiệu lên Facebook.

Đọc bình luận Facebook Page

Chỉ dùng cho Page bạn quản lý. Live trên trang cá nhân vẫn có thể phát hình/tiếng, còn ứng dụng hiện dùng bình luận thử trên web.
