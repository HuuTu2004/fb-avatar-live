# OpenAI research for live Vietnamese comment replies

Checked 2026-10-30 against official OpenAI documentation. API facts below come from the linked primary sources. The application-specific choices are design inferences and are implemented in [LLM_ARCHITECTURE.md](LLM_ARCHITECTURE.md).

1. **Responses API and strict JSON.** OpenAI recommends Responses for new text-generation work. Structured Outputs with `text.format` and strict JSON Schema constrain the shape of a decision, but the app still needs semantic checks for real comment IDs, source IDs and spoken text. [Text generation](https://developers.openai.com/api/docs/guides/text), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses).
2. **One generative model.** `gpt-6-luna` supports Responses, Structured Outputs and reasoning efforts `none`/`low`. We use Luna `none` for comment selection and Luna `low` for Vietnamese drafting. There is no automatic model upgrade. [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [Reasoning guide](https://developers.openai.com/api/docs/guides/reasoning).
3. **Moderation alongside generation.** The standalone Moderations endpoint classifies incoming comments. A top-level `moderation` field on a Responses request returns input/output signals; the output result is checked before TTS. The application maps the signals to automatic safe speech or withholding, with no human approval queue. [Moderation guide](https://developers.openai.com/api/docs/guides/moderation).
4. **Keep source and conversation control locally.** The app supplies short recent context and source summaries and sends `store:false` to Responses. A small versioned catalog is simpler than File Search for the first nine source cards; File Search becomes useful if the catalog grows enough to justify retrieval cost and latency. [Conversation state](https://developers.openai.com/api/docs/guides/conversation-state), [File Search](https://developers.openai.com/api/docs/guides/tools-file-search).
5. **Evaluate representative Vietnamese cases.** Test selection, prompt injection, source gaps, sensitive comments, names, length, deduplication and media recovery. Measure live quality and latency with anonymized samples. OpenAI recommends representative eval data and continuous measurement. [Evaluation best practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices).

Implementation inference: a reply may be marked delivered only after the local audio and video feeders report success. That is `fed_to_encoder`, not proof that Facebook/TikTok delivered it to a viewer. When delivery is uncertain, the app records that state and avoids automatic replay.
